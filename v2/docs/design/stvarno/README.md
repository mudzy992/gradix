# Snimci STVARNE aplikacije (dokaz)

Ovdje žive snimci onoga što aplikacija stvarno radi — za razliku od
`docs/design/referenca/` (reference.html = CILJ, kako treba da izgleda).

- **Web:** CI artefakt `gradix-snimci` (svaki CI run na grani, GitHub Actions →
  Artifacts). Obuhvata katalog i ključne stranice, obje teme, 360 i 1440 px.
  Snimci se ne commituju u repo — preuzimaju se s CI runa (link je u izvještaju).
- **Mobilni:** CI posao `mobile-snimci` (ručno/noćno, nije kapija) — artefakt
  `gradix-mobilni-snimci`. Dok se prvi artefakt ne pojavi, mobilni snimci
  stvarnog ekrana NE postoje i nijedan izvještaj ih ne smije podrazumijevati.

U izvještaju: referenca se nikad ne predstavlja kao stanje aplikacije.
